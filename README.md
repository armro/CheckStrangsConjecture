# Check Strang's Conjecture
This code should be ran on Google Colab.  

It includes four examples of meshes that we test Strang's conjecture for.  
- A mesh generated using NGSolve's built in mesh generator function
- Three handmade meshes
  - Including the Morgan-Scott mesh and a mesh with one singular vertex
- An imported mesh\*

\*   For imported meshes, ensure you have a .vol file present in your directory. When prompted to choose a file, select the .vol file corresponding to the mesh you'd like to test. 'sing_vert_mesh.vol' or '3sing_vert_mesh.vol' can be downloaded and tested for this example.
